Overview

For my third COMP 211 checkoff, I explored stack buffer overflows and their relationship to memory safety and cybersecurity.

A buffer overflow occurs when a program writes more data into a buffer than it has space to hold. A stack buffer overflow occurs when a program writes data beyond the capacity of a stack-allocated buffer.

I chose this topic because I'm interested in cybersecurity and wanted to better understand how concepts from COMP 211 can relate to real-world security vulnerabilities.
